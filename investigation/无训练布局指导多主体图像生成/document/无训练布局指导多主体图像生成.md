# 无训练布局指导多主体图像生成

> **调研背景**: 多主体图像生成要求模型在遵循文本提示的同时，让每个主体落在用户指定的空间位置上。传统布局到图像（layout-to-image）路线依赖大规模成对 layout-image 标注与额外训练，成本高且受闭集类别限制。本调研聚焦 **training-free** 路线：不新增训练、不微调扩散骨干，仅通过推理期的注意力操作、交叉注意力约束与能量引导，实现布局指导的多主体生成。目的是梳理该方向 2023–2025 年的代表性方法，比较它们控制布局的手段、机制与代价。
> **调研范围**: 2022–2025 年，入选论文 5 篇（FULL_TEXT 5 篇，仅摘要来源 0 篇）

# 1. 逐篇定位

## 1.1 BoxDiff

BoxDiff 针对 fully-supervised layout-to-image 依赖大量成对标注、且受闭集类别限制的问题，提出**不训练任何模块**、仅在去噪步内对交叉注意力图施加三项空间约束（Inner-Box / Outer-Box / Corner），并把约束梯度回加到当前 latent 上。它是本课题中"**把布局约束写成注意力图上的能量项**"这一路线的开创性工作，后续多篇方法都沿用了"提取注意力图 → 计算约束 → 梯度修正 latent"的基本骨架。

## 1.2 AttnRefocusing

AttnRefocusing 指出多主体、多属性提示下模型仍会出现对象缺失与属性混合，并进一步指出已有工作只操纵 cross-attention map、**忽视了 self-attention 层中的同类问题**。它的做法是用 GPT-4 由文本提示生成显式布局，再在采样期用 CAR（交叉注意力重聚焦）与 SAR（自注意力重聚焦）两个损失修改带噪样本。它是本课题中**把注意力干预从交叉注意力扩展到自注意力**的代表，且强调只优化注意力图的峰值而非多个值，以保住图像质量。

![AttnRefocusing 两阶段 pipeline](../analysis/figures/AttnRefocusing_Fig3.png)

> 图注原文：Figure 3. Our pipeline. Our approach includes 1) text-to-layout using GPT-4 model and 2) grounded text-to-image using a pre-trained diffusion model with our attention-refocusing.

![AttnRefocusing 框架与损失结构](../analysis/figures/AttnRefocusing_Fig2.png)

> 图注原文：Figure 2. The proposed Attention-Refocusing framework. At each denoising step, we update the noised sample by optimizing our LCAR and LSAR losses (red block) before denoising with the predicted noise (yellow block). For each cross-attention map, LCAR is designed to encourage a region to attend more to the corresponding token while discouraging the remaining region from attending to that token. For each self-attention map, LSAR prevents the pixels in a region from attending to irrelevant regions (LCAR and LSAR in blue blocks).

![CAR 与 SAR 的注意力重聚焦可视化](../analysis/figures/AttnRefocusing_Fig4.png)

> 图注原文：Figure 4. (a) Cross-Attention-Refocusing (CAR) visualization. Without CAR, the token "parrot" attends to background regions. Using CAR calibrates the cross-attention map to attend to the correct regions. (b) Self-Attention-Refocusing (SAR) visualization. The dots in each box represent the pixel query of the self-attention map. Applying SAR loss helps refocus the self-attention layer to attend less to the incorrect regions.

## 1.3 SpotActor

SpotActor 首次形式化 **L2CI（Layout-to-Consistent-Image）** 任务，要求一组图像既保持主体外观跨图一致、又落在指定框内，并指出此前的 subject consistency 与 layout controllability 一直是两个互不相干的话题。它把语义空间与潜空间视为一个**对偶空间**，提出双能量引导：每个采样步先做布局条件化的反向更新（对 latent 与语义 embedding 同时做梯度下降），再做一致性前向采样（RISA 与 SFCA 两个注意力机制）。它是本课题中**唯一同时处理"布局对齐"与"跨图主体一致性"**的一篇。

![SpotActor 方法框架](../analysis/figures/SpotActor_Fig2.png)

> 图注原文：Figure 2: The overall architecture of SpotActor. (a) Our method consists of two stages at each sample step in a dual energy guidance manner. The backward stage optimizes the latent codes and semantic embeddings with the nuanced layout energy based on the sigmoid-like objective. Subsequently, the forward sampling is enhanced by two intricate attention mechanisms: (b) RISA and (c) SFCA.

![SpotActor 注意力分析与 sigmoid-like 近似分布](../analysis/figures/SpotActor_Fig3.png)

> 图注原文：Figure 3: Illustration of the attention analysis. (a) IntraM is the attention map normalized within each token, while (b) InterM is normalized across all the tokens. We further visualize (c) 3D distributions of attention maps and propose (d) sigmoid-like approximate distributions.

## 1.4 ISAC

ISAC 关注免训练多实例生成中的**计数失败**与**语义混淆**，并诊断出已有方法的结构分组仍以交叉注意力语义为条件，因而无法区分共享同一语义 token 的多个实例。它提出 **instance-first hierarchy**：Phase 1 用自注意力聚类出类别无关的实例掩码并以 MPO 惩罚重叠，Phase 2 再把语义绑定进这些稳定结构，两阶段由固定的实例到语义调度衔接。它是本课题中**把"结构先于语义"作为显式设计原则**的一篇，并同时给出 latent optimization 与 latent selection 两种推理变体。

![ISAC 方法框架](../analysis/figures/ISAC_Fig4.png)

> 图注原文：Fig. 4: Overview of ISAC. Guided by diffusion dynamics, ISAC computes a hierarchical objective in two phases. Phase 1 (Sec. 3.2) clusters self-attention to shape N class-agnostic instance layouts, repelling overlaps to establish clean boundaries early in the trajectory. Phase 2 (Sec. 3.3) then inject these reliable instance structures into cross-attention to align semantic evidence, using a repel-and-bind loss to prevent cross-instance semantic mixing. An instance-to-semantic schedule (Sec. 3.4) seamlessly transitions the objective from Phase 1 to Phase 2.

![ISAC 关键机制：扩散动力学](../analysis/figures/ISAC_Fig3.png)

> 图注原文：Fig. 3: Dynamics of text-to-image diffusion models. In the early stages of diffusion, instance structures emerge [39] while semantics remain underdeveloped. In later diffusion steps, instance structures are stabilized, and semantic refinements happen. Because detection models (e.g., [53]) rely on strong semantic cues, they are effective only in later steps. We use a prompt of "A photo of a cat and a dog" on SD3.5-M [23].

## 1.5 AnyMS

AnyMS 针对布局指导多主体定制中"文本对齐、身份保持、布局控制"三者难以兼顾、且现有方法依赖额外训练的问题，提出**自底向上双层注意力解耦**：全局层把文本 cross-attention 与图像 cross-attention 分成两条独立流，局部层用 bbox 把每个空间区域限制为只关注其指定主体。它用预训练 image adapter 直接提取主体特征，从而免去主体学习与 adapter 调优，是本课题中**对"多条件竞争"给出结构性回答、且明确以 training-free 为卖点**的一篇。

![AnyMS 方法框架](../analysis/figures/AnyMS_Fig3.png)

> 图注原文：Figure 3. The Overview of Pipeline. AnyMS applies a dual-level attention decoupling strategy alongside the general denoising process of the diffusion model. (a) The global decoupling separates cross-attention between text and subject images. (b) The local decoupling further disentangles image cross-attention based on layout constraints. The final z0 is then decoded back to target image IG.

# 2. 对比分析

## 2.1 方法框架对比

| 对比维度 | BoxDiff | AttnRefocusing | SpotActor | ISAC | AnyMS |
| -------- | ------- | -------------- | --------- | ---- | ----- |
| 模块划分 | Cross-Modal Attention 提取 + 三项空间约束（IB/OB/CC） | Text-to-layout（GPT-4）+ CAR + SAR | 双能量引导形式化 + Layout-Conditioned Backward Update + Consistent Forward Sampling（RISA + SFCA） | Attention Hooks + Phase 1 Instance Formation + Phase 2 Instance-aware Semantic Separation | Global Decoupling + Local Decoupling（含 training-free 主体特征提取、attention cropping and merging） |
| 数据流 | 每步提取交叉注意力 → 算三项约束 → 梯度修正 latent → 常规去噪 | GPT-4 生成 box → 每步算 CAR/SAR → 梯度更新带噪样本 → 交回 UNet 去噪 | 每步先对 latent 与语义 embedding 做能量梯度下降 → 再在增强 U-Net 中做跨图注意力前向采样 | 每步读 SA/CA → 聚类出实例掩码算 L_ins → 由 SA·CA 算语义 repel/bind → 按调度合成总目标后更新或打分 | 每个 cross-attention 层：文本流 + 图像流（按 bbox 裁 query 做局部 attention 再写回）→ 逐 timestep 累加 |
| 空间约束来源 | 用户给定 box / scribble | LLM 由文本提示生成的 box（也支持 seg mask 等模态） | 用户给定 bounding box + 主体描述 + 情节描述 | 提示词解析出的类 tag–count 对与 token 关系（无显式 box） | 用户给定「主体图像–布局」对 |
| 干预的注意力类型 | 仅 cross-attention | cross-attention + self-attention | cross-attention（能量）+ self/cross-attention（RISA/SFCA 结构改造） | self-attention（结构）+ cross-attention（语义） | cross-attention（全局分离 + 局部裁剪） |
| 是否改动模型结构 | 否，plug-and-play | 否，model-agnostic | 是，U-Net 上加 RISA/SFCA 两个推理期模块 | 否，仅注册 hook 读注意力 | 否，仅改写 cross-attention 计算 |
| 是否引入新增可训练参数 | 否 | 否 | 否（模块为推理期手工设计，无可训练参数） | 否 | 否（复用预训练 image adapter） |

**分野**：五篇都不训练参数，差别在于**把布局约束施加在哪个量上**。BoxDiff 与 AttnRefocusing 施加在注意力图的**数值响应**上（抬高框内、压低框外）；SpotActor 把它写成对**注意力分布形态**的拟合（2 维 Sigmoid 峰形能量）；ISAC 把它转化为**实例掩码之间的重叠惩罚**；AnyMS 则根本不动注意力数值，而是用 bbox **裁剪 query 的作用范围**。约束对象从"值"到"分布"到"结构"再到"作用域"，恰好是这条路线逐步抽象化的过程。

## 2.2 关键机制对比

| 论文 | 核心机制 | 解决什么 | 代价 / 局限 |
| ---- | -------- | -------- | ----------- |
| BoxDiff | Inner-Box 抬高框内响应、Outer-Box 压制框外响应、Corner 在 x/y 投影上对齐尺度 | 无成对标注数据下按框控制对象位置与尺度 | 需用户给出 box；过强约束会损害图像保真度，故用 topk/sample 只约束部分元素 |
| AttnRefocusing | CAR 让框内更关注对应 token、框外抑制；SAR 让框内像素少关注框外区域 | 多主体缺失/混合，以及 self-attention 中未被处理的同类问题 | 依赖 GPT-4 生成布局；每个早期去噪步需多次迭代更新，推理开销随 τ 上升 |
| SpotActor | 用 2 维扩展 Sigmoid 拟合 intra-token 峰形激活作为布局能量，同时对 latent 与语义 embedding 做梯度下降；RISA/SFCA 做跨图注意力互联 | 布局对齐与跨图主体一致性从未被同时解决 | 改动 U-Net 注意力结构；每步需额外反向更新迭代 |
| ISAC | Phase 1 用 K-means 聚类自注意力行得到类别无关实例掩码，以 MPO 惩罚最坏重叠；Phase 2 用 repel-and-bind 把语义绑定进实例掩码 | 多实例计数失败与跨实例语义混淆 | 需提示词给出可解析的类 tag–count；论文明确把计数歧义提示排除在范围外 |
| AnyMS | 全局把 Z_out 拆为 Z_text + Z_image 两条流；局部按 bbox 裁出 query 子区域做 image cross-attention 再写回，重叠区按语义优先级消解 | 文本、视觉、布局三条件互相竞争，且要求免训练 | 效果上限受预训练扩散模型与 image adapter 能力约束；主体数、场景复杂度与特征提取鲁棒性存在上限 |

**共同的收敛点**：五篇最终都回到同一条主线——**限制某个条件能影响哪些空间位置或哪些 token**。BoxDiff / AttnRefocusing 靠"响应值的高低"实现，SpotActor 靠"响应分布的形状"，ISAC 靠"实例区域之间的重叠"，AnyMS 靠"query 的空间裁剪"。这一收敛也解释了为什么五篇都必须是 training-free 的：约束直接作用在推理期的中间量上，不需要把布局先验固化进参数。

# 3. 结论与开放问题

**共识**：五篇都认同一件事——多主体布局生成的核心困难是**多个条件在同一空间位置上竞争**，因此都必须回答"谁在什么位置说话"。也正因为约束可以直接施加在推理期的中间量上，五篇都选择了 training-free 路线，且都无需成对 layout-image 标注数据。这构成本课题最稳固的共识：**布局指导不必以训练为代价**。

**分歧**：分歧集中在**约束施加在哪个量上、以及是否需要显式 box**。

1. **约束对象**：BoxDiff 与 AttnRefocusing 直接改写注意力图的数值响应；SpotActor 改为拟合注意力的分布形态；ISAC 改为惩罚实例掩码之间的重叠；AnyMS 则绕过注意力数值、直接裁剪 query 的空间作用域。四种做法对"布局精度 vs 图像保真度"的取舍并不相同——BoxDiff 明确报告过强约束会导致保真度崩溃，而 AnyMS 主张其方案只有"marginal inference overhead"。
2. **布局来源**：AttnRefocusing 用 LLM 由文本自动生成 box，BoxDiff / SpotActor / AnyMS 依赖用户显式给出 box，ISAC 则完全不用 box、改由提示词解析出的类 tag–count 驱动。**是否需要用户提供显式布局，是这五篇最实质的路线分歧。**

**尚未解决的问题**：

1. **布局来源的自动化程度**：只有 AttnRefocusing 尝试用 LLM 自动推断布局，其余四篇仍依赖用户输入或提示词解析，尚无一篇解决"从纯文本自动推断多主体布局"。
2. **training-free 的能力上限**：AnyMS 在 Limitations 中已明确承认其效果依赖预训练扩散模型与 image adapter 的能力，主体数量、场景复杂度与特征提取鲁棒性都存在上限；ISAC 也把计数歧义的提示词排除在范围外。**"不训练能做到哪一步"仍无定论。**
3. **评测口径不统一**：五篇分别使用 DrawBench / HRS / TIFA（AttnRefocusing）、自建组合（AnyMS 的 11 个组合）、多实例基准（ISAC）等不同基准与指标，布局精度、身份保真度与文本对齐之间如何权衡缺乏统一量尺，跨方法的强弱结论难以直接比较。
4. **多主体数量与一致性的耦合**：SpotActor 处理的是跨图一致性，AnyMS 处理的是单图多主体定制，两者都涉及"多主体"，但关注的一致性维度不同，尚无工作把二者放在同一框架下考察。
